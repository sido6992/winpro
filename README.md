# WIN PRO — Deriv OAuth 2.0 (PKCE) + Render backend

## Deploy on Render
1. Push this folder to a GitHub/GitLab repo.
2. Render → New → Blueprint (uses render.yaml) or New → Web Service (Build: `npm install`, Start: `node server.js`).
3. Env vars: `SESSION_SECRET` (long random string; generated by render.yaml), `DERIV_CLIENT_ID` (34tb6qr80U6IIGqopktV4).
4. In your Deriv app settings, register the redirect URI: `https://<your-service>.onrender.com/callback`
   (custom domain? register `https://your.domain/callback` and set env `REDIRECT_URI` to the same value).

## Flow
Browser → auth.deriv.com (PKCE) → /callback → POST /api/session (server exchanges code) → encrypted httpOnly cookie
→ GET /api/accounts → POST /api/accounts/:id/otp → browser opens the returned WebSocket URL.
